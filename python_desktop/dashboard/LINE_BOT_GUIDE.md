# LINE Bot 測試指令參考文件

## 📱 Bot 功能概覽

這個 LINE Bot 可以讓使用者透過 LINE 聊天介面查詢股市新聞、情緒分析和熱門股票資訊。

---

## 🎯 支援的指令

### 1. 查詢特定股票新聞
**指令格式:**
```
查詢 [股票名稱或代碼]
```

**範例:**
```
查詢 台積電
查詢 2330
查詢 鴻海
```

**回應內容:**
- 最新 5 則相關新聞
- 新聞標題
- 情緒分數 (1-9)
- 發布來源
- 發布時間

**情緒圖示說明:**
- 📈 正面情緒 (分數 ≥ 7)
- 📉 負面情緒 (分數 ≤ 3)
- ➡️ 中性情緒 (分數 4-6)

---

### 2. 查看熱門股票
**指令:**
```
熱門
```

**回應內容:**
- 最活躍的 TOP 10 股票
- 顯示股票名稱和新聞數量
- 按新聞數量排序

**範例回應:**
```
🔥 最活躍股票 TOP 10：

1. 台積電 (156 則新聞)
2. 鴻海 (89 則新聞)
3. 聯發科 (67 則新聞)
...
```

---

### 3. 查看最新新聞
**指令:**
```
最新
```

**回應內容:**
- 最新 5 則股市新聞
- 包含股票名稱、標題、情緒分數

**範例回應:**
```
📰 最新股市新聞：

📈 台積電 [8]
台積電Q4營收創新高，法人看好後市

➡️ 鴻海 [5]
鴻海電動車布局再下一城
...
```

---

**範例回應:**

### 5. 查看負面情緒新聞
**指令:**


**回應內容:**
- 情緒分數 1-3 的新聞
- 最新 5 則
- 適合追蹤風險消息

**範例回應:**

**範例回應:**

## 🛠️ 本地測試流程

### 1. 啟動 Flask 應用
```bash
cd D:\__mypostgres_test\python_desktop\dashboard
python app.py
```

### 2. 啟動 ngrok
```bash
C:\ngrok\ngrok.exe http 5000
```

### 3. 設定 LINE Webhook
1. 複製 ngrok 提供的 HTTPS URL
2. 前往 [LINE Developers Console](https://developers.line.biz/console/)
3. 選擇你的 Messaging API Channel
4. 在 Webhook settings 中設定:
   ```
   https://your-ngrok-url.ngrok-free.dev/callback
   ```
5. 點擊 **Verify** 確認連線
6. 啟用 **Use webhook**

### 4. 測試 Bot
1. 用手機掃描 LINE Bot 的 QR Code 加入好友
2. 傳送測試指令
3. 觀察回應是否正確

### 5. 除錯
如果 Bot 沒有回應，檢查:
- Flask app 是否正常運行
- ngrok 是否正常運行
- LINE Webhook URL 是否正確
- 查看 Flask console 的 log
- 查看 LINE Developers Console 的 webhook log

## ⚠️ 注意事項

1. **ngrok 免費版限制**
   - 每次重啟 ngrok，URL 會改變
   - 需要重新設定 LINE Webhook URL
   - 建議測試時保持 ngrok 運行

2. **資料庫依賴**
   - Bot 需要連接到本地 PostgreSQL
   - 確保資料庫有資料才能正常查詢

3. **回應時間**
   - 首次查詢可能較慢（建立資料庫連線）
   - 後續查詢會較快

4. **LINE 限制**
   - 回應訊息有字數限制（約 5000 字）
   - 超過限制會被截斷

## 🐛 常見問題排解

### Q1: Bot 沒有回應
**檢查項目:**
- [ ] Flask app 是否運行中
- [ ] ngrok 是否運行中
- [ ] Webhook URL 是否正確設定
- [ ] .env 檔案是否有正確的 LINE credentials

### Q2: 查詢結果是空的
**可能原因:**
- 資料庫沒有該股票的資料
- 股票名稱拼寫錯誤
- 資料庫連線失敗

### Q3: 情緒分數沒有顯示
**可能原因:**
- 該新聞尚未進行情緒分析
- sentiment_score 欄位為 NULL

### Q4: ngrok URL 一直變
**解決方案:**
- 使用 ngrok 付費版（固定 URL）
- 或每次重啟後重新設定 LINE Webhook
