# LINE Bot 完整使用指南

## 📱 Bot 功能概覽

這個 LINE Bot 可以讓使用者透過 LINE 聊天介面查詢股市新聞、情緒分析和熱門股票資訊。

**主要功能：**
- 📰 查詢特定股票新聞
- 🔥 查看熱門股票排行
- 📊 查看情緒分析新聞
- 📅 查看一周新聞分析（整體 + 個股）

---

## 🎯 支援的指令

### 1. 查詢特定股票新聞

**指令格式:**
```
查詢 [股票名稱或代碼]
```

**範例:**
```
查詢 台積電
查詢 2330
查詢 鴻海
```

**回應內容:**
- 最新 5 則相關新聞
- 新聞標題
- 情緒分數 (1-9)
- 發布來源（Yahoo / 鉅亨網）
- 發布時間

**情緒圖示說明:**
- 📈 正面情緒 (分數 ≥ 7)
- 📉 負面情緒 (分數 ≤ 3)
- ➡️ 中性情緒 (分數 4-6)

---

### 2. 查看熱門股票

**指令:**
```
熱門
```

**回應內容:**
- 最活躍的 TOP 10 股票
- 顯示股票名稱和新聞數量
- 按新聞數量排序

**範例回應:**
```
🔥 最活躍股票 TOP 10：

1. 台積電 (156 則新聞)
2. 鴻海 (89 則新聞)

```

### 7. 查看特定股票一周分析 ⭐ 新功能

**指令格式:**
```
[股票名稱] 一周
[股票名稱] 本周
```

**範例:**
```
台積電 一周
鴻海 本周
2330 一周
```

**回應內容:**
- 📅 時間範圍（自動計算為今天往前推7天，例如：02/02 - 02/08）
- 📰 該股票總新聞數
- 📊 平均情緒分數（含情緒判斷：偏正面/中性/偏負面）
- 📈 正面新聞數量
- 📉 負面新聞數量
- 📝 最新 5 則新聞詳情（含標題、情緒分數、來源）

**範例回應:**
```
📊 台積電 一周新聞分析
📅 時間範圍：02/02 - 02/08

📰 總新聞數：21 則
📈 平均情緒：6.52 (偏正面)
📈 正面新聞：15 則
📉 負面新聞：2 則

📝 最新 5 則新聞：

1. 📈 [8] [Yahoo]
   台積電先進製程訂單滿載，法人看好Q1營收

2. ➡️ [5] [鉅亨網]
   台積電美國廠進度超前，預計提前量產

3. 📈 [7] [Yahoo]
   台積電獲大客戶追加訂單，產能利用率提升

4. ➡️ [6] [鉅亨網]
   台積電布局先進封裝，搶攻AI晶片商機

5. 📈 [8] [Yahoo]
   外資連續買超台積電，目標價上調至800元
```

**情緒判斷說明:**
- **偏正面** 📈：平均情緒 ≥ 6
- **中性** ➡️：平均情緒在 4-6 之間
- **偏負面** 📉：平均情緒 ≤ 4

## 🛠️ 本地測試流程

### 1. 啟動 Flask 應用
```bash
cd d:\__mypostgres_test\python_desktop\dashboard
python app.py
```

### 2. 啟動 ngrok
```bash
C:\ngrok\ngrok.exe http 5000
```

### 3. 設定 LINE Webhook
1. 複製 ngrok 提供的 HTTPS URL
2. 前往 [LINE Developers Console](https://developers.line.biz/console/)
3. 選擇你的 Messaging API Channel
4. 在 Webhook settings 中設定:
   ```
   https://your-ngrok-url.ngrok-free.dev/webhook
   ```
5. 點擊 **Verify** 確認連線
6. 啟用 **Use webhook**

### 4. 測試 Bot
1. 用手機掃描 LINE Bot 的 QR Code 加入好友
2. 傳送測試指令
3. 觀察回應是否正確

### 5. 除錯
如果 Bot 沒有回應，檢查:
- Flask app 是否正常運行
- ngrok 是否正常運行
- LINE Webhook URL 是否正確
- 查看 Flask console 的 log
- 查看 LINE Developers Console 的 webhook log

## 🔍 指令對比與選擇

### 一般查詢 vs 一周分析

| 指令 | 時間範圍 | 新聞數量 | 統計資訊 | 適用場景 |
|------|----------|----------|----------|----------|
| `查詢 台積電` | 所有時間 | 最新 5 則 | ❌ 無 | 快速瀏覽最新動態 |
| `台積電 一周` | 最近 7 天 | 全部 + 最新5則 | ✅ 完整統計 | 深入了解一周表現 |
| `一周` | 最近 7 天 | TOP 5股票 | ✅ 整體統計 | 了解市場整體趨勢 |

### 推薦使用流程

```
1. 一周           # 先了解整體市場趨勢
2. 熱門           # 看哪些股票最受關注
3. 台積電 一周    # 深入分析特定股票
4. 查詢 台積電    # 查看更多歷史新聞
5. 正面 / 負面    # 過濾特定情緒新聞
```

## ⚠️ 注意事項

1. **ngrok 免費版限制**
   - 每次重啟 ngrok，URL 會改變
   - 需要重新設定 LINE Webhook URL
   - 建議測試時保持 ngrok 運行

2. **資料庫依賴**
   - Bot 需要連接到本地 PostgreSQL
   - 確保資料庫有資料才能正常查詢
   - 定期執行爬蟲更新數據

3. **回應時間**
   - 首次查詢可能較慢（建立資料庫連線）
   - 後續查詢會較快
   - 一周分析可能需要幾秒處理時間

4. **LINE 限制**
   - 回應訊息有字數限制（約 5000 字）
   - 超過限制會被截斷

5. **時間範圍**
   - 一周分析固定為7天，不可自定義
   - 日期自動計算為今天往前推7天

6. **數據來源**
   - 僅包含 Yahoo 和鉅亨網
   - 情緒分數由 AI 分析產生，僅供參考

## 🐛 常見問題排解

### Q1: Bot 沒有回應
**檢查項目:**
- [ ] Flask app 是否運行中
- [ ] ngrok 是否運行中
- [ ] Webhook URL 是否正確設定
- [ ] .env 檔案是否有正確的 LINE credentials

**解決方案：**
1. 檢查 Flask console 是否有錯誤訊息
2. 確認 ngrok 顯示的 URL 與 LINE Webhook 設定一致
3. 嘗試重啟 Flask app 和 ngrok

### Q2: 查詢結果是空的
**可能原因:**
- 資料庫沒有該股票的資料
- 股票名稱拼寫錯誤
- 資料庫連線失敗
- 爬蟲未執行或數據過舊

**解決方案：**
1. 確認股票名稱或代碼正確
2. 執行爬蟲更新數據
3. 檢查資料庫連線

### Q3: 情緒分數沒有顯示
**可能原因:**
- 該新聞尚未進行情緒分析
- sentiment_score 欄位為 NULL

**解決方案：**
執行情緒分析腳本：
```bash
cd d:\__mypostgres_test\python_desktop\stocks_news
python yahoo/analyze_sentiment.py
python cnyes/analyze_sentiment.py
```

### Q4: ngrok URL 一直變
**解決方案:**
- 使用 ngrok 付費版（固定 URL）
- 或每次重啟後重新設定 LINE Webhook

### Q5: 一周分析沒有數據
**可能原因:**
- 該股票在最近7天沒有新聞
- 爬蟲未執行近期數據

**解決方案：**
1. 確認資料庫有近7天的數據
2. 執行爬蟲更新數據
