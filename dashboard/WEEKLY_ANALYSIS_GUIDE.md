# 一周新聞分析功能使用說明

## 📋 功能概述

本次更新為股市新聞系統添加了**最近一周新聞分析**功能，可以通過 Dashboard 和 LINE Bot 查詢過去7天的新聞統計、情緒趨勢和熱門股票。

---

## 🎯 Dashboard 新增功能

### 1. 本周新聞統計卡片（4個彩色卡片）

顯示最近7天的關鍵指標：
- **本周總新聞**：過去7天抓取的新聞總數
- **平均情緒**：過去7天所有新聞的平均情緒分數（1-9）
- **正面新聞**：情緒分數 ≥ 7 的新聞數量
- **負面新聞**：情緒分數 ≤ 3 的新聞數量

### 2. 本周最熱門股票 TOP 5

列出過去7天新聞數量最多的前5檔股票，包括：
- 股票名稱
- 新聞數量

### 3. 一周情緒趨勢圖

折線圖顯示：
- X軸：過去7天的日期
- Y軸：每天的平均情緒分數（0-9）
- 可以直觀看出市場情緒的變化趨勢

## 💬 LINE Bot 新增指令

### 指令格式

```
一周
```
或
```
本周
```

### 回應內容

Bot 會回覆包含以下信息的訊息：

```
📊 最近一周新聞分析

📰 總新聞數：287 則
📈 平均情緒：5.67
📈 正面新聞：45 則
📉 負面新聞：23 則

🔥 本周最熱門股票：
1. 台積電 (67 則)
2. 鴻海 (43 則)
3. 聯發科 (38 則)
4. 台達電 (29 則)
5. 廣達 (24 則)
```

### 情緒圖示說明

- 📈：平均情緒 ≥ 6（市場偏正面）
- ➡️：平均情緒在 4-6 之間（市場中性）
- 📉：平均情緒 ≤ 4（市場偏負面）

## 🔧 技術實現

### 後端 API

新增了2個 API endpoints：

#### 1. `/api/weekly_analysis`
返回一周新聞分析數據：
```json
{
  "total_news": 287,
  "avg_sentiment": 5.67,
  "positive_count": 45,
  "negative_count": 23,
  "top_stocks": [
    {"stock_name": "台積電", "news_count": 67},
    ...
  ]
}
```

#### 2. `/api/weekly_sentiment_trend`
返回一周每天的情緒趨勢：
```json
{
  "labels": ["02/03", "02/04", "02/05", ...],
  "data": [5.2, 5.8, 5.6, ...]
}
```

### 前端實現

- 使用 Chart.js 繪製情緒趨勢折線圖
- 使用 CSS 漸變背景美化統計卡片
- 每30秒自動刷新數據

### LINE Bot 實現

新增 `get_weekly_analysis_text()` 函數：
- 查詢過去7天的新聞數據
- 計算各項統計指標
- 格式化為易讀的訊息文本

---

## 📊 數據範圍

所有一周分析功能都基於：
- **時間範圍**：當前日期往前推7天
- **數據來源**：Yahoo 新聞 + 鉅亨網新聞（合併）
- **過濾條件**：使用 `fetched_date >= CURRENT_DATE - INTERVAL '7 days'`

## 🚀 如何使用

### 查看 Dashboard

1. 啟動 Flask 應用：
```bash
cd d:\__mypostgres_test\python_desktop\dashboard
python app.py
```

2. 瀏覽器訪問：`http://localhost:5000`

3. 頁面會自動顯示一周分析區塊，包括：
   - 彩色統計卡片
   - 熱門股票列表
   - 情緒趨勢圖

### 使用 LINE Bot

1. 確保 LINE Bot 已正確設置（需要 `LINE_CHANNEL_SECRET` 和 `LINE_CHANNEL_ACCESS_TOKEN`）

2. 在 LINE 中向 Bot 發送：
```
一周
```
或
```
本周
```

3. Bot 會立即回覆一周新聞分析結果
